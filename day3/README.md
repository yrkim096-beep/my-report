## Playwright로 실제 확인한 것

- 리포트 화면에 "제안서(임시)" 탭이 더 이상 없음
- 사이드바에 "제안서" 메뉴가 보이고, 클릭하면 새 페이지로 이동함
- 주제를 "담당자별 전환율 격차"로 바꾸면 문서 전체(요약·차트·카드)가 그 주제 기준으로 다시 조립됨
- 2번 절(원인)에 담당자별 가로 막대 차트가 실제로 그려짐(최고=초록, 최저=빨강, 나머지=회색)
- 4번 절(제안)에 이 주제와 관련된 카드만 걸러져서 나옴(유입채널 카드는 안 섞임)
- 5·6번(사람 절) 저장 → HTML 다운로드 → 저장한 문장이 실제로 파일에 반영됨을 확인
- 다운로드한 HTML을 브라우저에 그대로 열어 표지·한 장 요약·6개 절·카드·차트가 전부 정상 렌더링됨을 스크린샷으로 확인
