# Day5 산출물

9주차 Day5(토) — 개인 실습 프로젝트 날. 정해진 시간표 없이 트랙 중 하나를 골라 진행한다.
**트랙 A(아직 밀린 게 있다)**와 **트랙 B(제안서까지는 끝났다 — 벤치마크 피드백 반영)**를
차례로 진행했다.

| 산출물 | 위치 |
|---|---|
| 트랙 A — 시작 전 확인할 것 다섯 대조 결과 | `day5/체크리스트.md` |
| 트랙 A — 빈칸이었던 카드 확신도 채움 | `day2/제안카드.md` (반증·받은 반박 표 3장 전부) |
| 트랙 B — 외부 평가(Decision Room) 반영 기록 | `day5/트랙B.md` |
| 트랙 B — 갱신된 제안서(대상 확대: 담당자 3명, 규모 9.7건/년) | `day5/제안서_트랙B_최종.html` · `.pdf` |
| 트랙 B — 판단기준.md 마무리(적용 다섯 줄) | `day5/판단기준_적용.md` |

## 9주가 끝난다

| | | |
|---|---|---|
| 1~6주차 | 도구를 다루는 법을 배웠다 | |
| 7주차 | 질문을 만들었다 | 문서 |
| 8주차 | 도구를 만들었다 | 앱 |
| 9주차 | 결론을 냈다 | 제안서 + (벤치마크 자리는 실재 서비스가 아니라 스킵) |

오늘 나가는 것은 앱이 아니라 `판단기준.md`에 쌓인 판단 기준 여덟 장이다 — 도메인 이름이
없어 다음에 다른 데이터를 만나도 그대로 쓸 수 있다. 앱은 데이터가 바뀌면 고쳐야 하고,
제안서는 이번 분기가 지나면 낡지만, 판단기준.md는 안 바뀐다.
