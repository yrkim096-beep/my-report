# Day2 산출물

9주차 Day2 — "이 제안을 앱에서 바로 볼 수 있는가"

| 산출물 | 위치 | 완성 기준 |
|---|---|---|
| 제안 카드 2~3장 | `day2/제안카드.md` | 근거·비용·효과·되돌림, "하지 말 것" 1개 이상 |
| 카드를 절로 조립하는 함수 | `report/proposal.py` (앱 코드라 리포지토리 루트 `report/`에 둔다 — 임포트돼야 하므로) | 자동/사람 절이 코드로 나뉨 (`build()`) |
| 화면에 뜨는 제안서 | `pages/3_리포트.py` 의 "제안서(임시)" 탭 | 리포트 화면에 임시 탭으로 붙음 |
| 문장 검사 | `report/proposal.py` 가 `report/sections.py`의 `check_phrasing`/`BANNED` 재사용 | 자동 절에 인과 단정 표현 없음 (Playwright로 실제 확인) |
| HTML 다운로드 | 탭 하단 "제안서 HTML 내려받기" 버튼, 실제로 받은 파일 → `day2/제안서.html` | 버튼을 누르면 파일이 내려받아짐 (확인 완료) |
| 판단 기준 한 장 | `판단기준.md`의 "9주차 Day2" 절 | 도메인 단어 없음 |

## 무엇을 자동으로, 무엇을 사람이 썼는가

| 절 | 누가 | 왜 |
|---|---|---|
| 한 장 요약 | 자동 | 카드·퍼널에서 그대로 뽑히는 사실 |
| 1. 무엇을 발견했는가 | 자동 | `core.metrics.funnel()` 조회 결과 |
| 2. 왜 이런 일이 생겼는가 | 자동 | `funnel_by()` 조회 결과 + 배제 못 한 것 |
| 3. 무엇을 하자고 제안하는가 | 자동 | 카드(`제안카드.md`)를 그대로 옮김 — 새로 짓지 않음 |
| 4. 이 제안이 틀린다면 | **사람** | 무엇이 틀릴 수 있는지·철회 조건은 판단이다 |
| 5. 적용 | **사람** (후보는 자동) | 후보는 `판단기준.md`에서 기계적으로 뽑되, 고르는 것은 사람 |
