## 제안 1 — 유입채널별 마케팅 예산을 지금 데이터만으로 재배분하지 않는다

| | |
|---|---|
| **분류** | 하지 말 것 |
| **근거** | 중개사 32.2% (38/118) vs 중개플랫폼 37.0% (71/192). 격차 4.8%p · 비중 29.2%(병목 구간 도달자 404명 중 중개사 118명) |
| **비용** | 해당 없음 — 지금 하는 배분을 유지하는 안이라 추가 비용이 들지 않는다 |
| **효과** | 관측 — 격차 자체는 실측이지만 연간 환산 규모가 약 3.6건/년으로 작다. 예산 재배분을 정당화할 만큼 크지 않다 |
| **되돌림** | 해당 없음 — 아무것도 바꾸지 않는 안이다 |

### 반증
이 제안이 틀렸다면 채널 간 격차가 우연이 아니라 꾸준히 유지되는 실제 차이여서일 것이다.
확인하려면 관측 기간을 전반부·후반부로 나눠 같은 격차가 유지되는지를 보면 된다.

| 확인 결과 | |
|---|---|
| 무엇을 봤는가 | 관측 기간을 전반부(2024-06~2025-03)·후반부(2025-03~2025-12)로 나눠 같은 구간(현장 방문 예약·진행→계약 체결)의 채널별 전환율을 다시 계산했다 |
| 뒤집혔는가 | 아니다 — 중개플랫폼이 두 구간 모두에서 중개사보다 높았다(전반부 36.0% vs 29.8%, 격차 6.2%p / 후반부 38.0% vs 34.4%, 격차 3.6%p). 방향은 유지되지만 격차 크기는 후반부에 더 작아졌다 |
| **확신도** | 추정 — 방향은 안정적이지만 격차가 줄어드는 추세라, "지금 데이터만으로는 재배분 근거가 약하다"는 이 카드의 결론(하지 말 것)이 오히려 더 힘을 얻었다 |

### 받은 반박
| | |
|---|---|
| 무엇을 지적받았나 | 없음 — 이번 라운드의 페르소나·동료 지적은 담당자(제안 3) 카드에 집중됐다 |
| 어떻게 처리했나 | 해당 없음 |
| **안 받아들였다면 왜** | 해당 없음 |
| 확신도가 바뀌었나 | 아니다(그대로 추정) |

## 제안 2 — 표본 미달로 감춰진 담당자 4명의 병목 구간 전환율을 다시 잰다

| | |
|---|---|

| **근거** | CS03(41건)·CS05(49건)·CS07(45건)·CS08(42건)이 표본 41~49건으로 최소 기준(50건) 미달 — 지금은 계산 자체를 하지 않은 상태다(감춘 것이지 나쁜 것이 아니다) |

| **효과** | 미확인 — 알 수 없다. "효과 없음"이 아니라 "판정 불가"다 |

### 반증
이 제안이 틀렸다면 표본이 쌓여도 격차가 사라질 것이다.
확인하려면 각 담당자 배정 건수가 50건을 넘긴 뒤 다시 전환율을 계산해서 보면 된다.

| 뒤집혔는가 | 해당 없음(아직 확인 전) |
| **확신도** | 미확인 — 담당자별 신규 배정 속도를 보고 표본이 쌓이는 시점에 다시 확인한다 |

## 제안 3 — 담당자 CS02·CS04·CS06의 상담 방식을 CS01 방식에 맞춰 조정한다

★ 9주차 Day5 — 외부 검토(Decision Room)에서 "개선 대상이 CS06 한 명뿐이라 사업적 임팩트가
작다"는 지적을 받고 범위를 넓혔다. 표본이 충분한 담당자 4명(CS01·CS02·CS04·CS06) 중
CS01을 제외한 나머지 셋이 전부 CS01보다 낮으므로, 그 셋을 모두 대상으로 넓혔다.

| | |
|---|---|
| **분류** | 할 것 |
| **근거** | CS01 38.9%(21/54)가 가장 높고, CS04 33.8%(22/65)·CS02 31.0%(18/58)·CS06 24.0%(12/50)이 모두 그보다 낮다. 격차(CS01-CS06) 14.9%p · 표본 흔들림 폭 2.0%p로 격차보다 작아 믿을 수 있다 |
| **비용** | 가정 — 코칭에 드는 시간(1회성, 3명분). 담당 조직: 영업관리팀장 주관·인사팀 협조. 확정 절차: 착수 승인 후 1주 내 담당자별 코칭 방식·소요 시수를 확정한다. **정확한 총 시수·비용은 아직 산정하지 않았다** — 코칭 방식이 안 정해져 지금 숫자를 만들면 거짓이 된다 |
| **효과** | 관측 CS01 38.9%(21/54) · 가정 CS02·CS04·CS06 셋 모두 CS01 수준까지 개선된다고 가정 · 추정 연간 약 9.7건 추가 전환(가정 위의 계산 — 담당자 1명이 아니라 표본 충분한 하위 3명 전원 기준) |
| **되돌림** | 가능 — 상담 방식 조정은 되돌릴 수 있는 개입이다 |

### 반증
이 제안이 틀렸다면 CS06이 배정받은 리드 자체가 더 어려운 조건(채널·매물유형)이어서일 것이다.
확인하려면 CS06과 CS01이 담당한 리드의 채널·매물유형 구성비를 대조해서 보면 된다.

| 확인 결과 | |
|---|---|
| 무엇을 봤는가 | consultations×leads를 조인해 CS06(134건)·CS01(117건)이 담당한 리드의 채널·매물유형 분포를 대조했다 |
| 뒤집혔는가 | 완전히는 아니다 — 두 담당자 모두 구성비가 5~9%p 이내로 비슷했다(중개플랫폼 45.9% vs 54.5%, 원룸 53.0% vs 49.6%). 배정 편향 가능성은 낮아졌지만 배정 시점 등 확인 못 한 특성이 남아 완전히 배제하지는 못했다 |
| **확신도** | 추정 — 배정 편향 가능성이 낮아져 "할 것" 결론이 더 힘을 얻었지만, 상담 방식 자체의 효과를 확인한 것은 아니다 |

### 받은 반박
| | |
|---|---|
| 무엇을 지적받았나 | (1) 배정 편향 가능성 확인 안 됨 (2) 철회 조건 "30%"의 근거가 안 보임 (3) 되돌림 가능 여부가 한 장 요약에는 안 보임 |
| 어떻게 처리했나 | (1)(2) 확인함 — 위 반증 확인 결과 및 철회 조건에 근거(현재 격차의 절반 회복)를 반영. (3) 확인함 — `report/proposal.py`의 한 장 요약에 되돌림 표시를 바로 붙임 |
| **안 받아들였다면 왜** | 코칭 비용(소요 시수)이 확인 필요로 남았다는 지적은 안 받아들였다 — 실제 코칭 운영 계획이 아직 없어 시수를 지어낼 수 없었다 |
| 확신도가 바뀌었나 | 아니다(그대로 추정) — 배정 편향 가능성이 낮아졌다는 근거가 추가됐지만 인과를 확정한 것은 아니다 |

### 받은 반박 (2차 — Decision Room 외부 평가, 9주차 Day5)
| | |
|---|---|
| 무엇을 지적받았나 | (1) 개선 효과가 연 4.7건으로 낮아 사업적 임팩트가 불분명하다 (2) 구체적인 실행 일정과 담당 조직이 없다 (3) 비용(소요 시수) 산정이 누락됐다 |
| 어떻게 처리했나 | (1) 확인함 — 대상을 CS06 한 명에서 표본 충분한 하위 담당자 3명(CS02·CS04·CS06) 전원으로 넓혀 실제로 다시 계산했다(4.7건→9.7건/년). (2) 확인함 — 담당 조직(영업관리팀장·인사팀)과 확정 절차(착수 승인 후 1주 내 확정)를 추가했다. (3) 안 받아들임 |
| **안 받아들였다면 왜** | 코칭 비용(시수) 산정은 이번에도 안 받아들였다 — 코칭 방식 자체가 아직 안 정해져 시수를 지어낼 근거가 없다. 대신 "언제까지, 누가 정하는가"(확정 절차)는 명시했다 — 숫자를 지어내지 않으면서도 구멍을 요청으로 바꿀 수 있는 부분은 바꿨다 |
| 확신도가 바뀌었나 | 아니다(그대로 추정) — 대상 범위를 넓혀 규모가 커졌을 뿐, 상담 방식 자체의 인과 효과를 새로 확인한 것은 아니다 |
